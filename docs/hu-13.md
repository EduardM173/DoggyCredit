# HU-13: Habilitar y consultar la fuente Buró para mi institución

La ruta `/:tenantSlug/fuentes-financieras` permite a la administradora institucional (`INSTITUTION_ADMIN`) consultar el catálogo de fuentes disponibles para su entidad (Fuente bancaria simulada `BANK_MOCK` y Buró crediticio simulado `BUREAU_MOCK`) y habilitar o deshabilitar cada fuente de forma aislada por tenant.

## Aspectos destacados de arquitectura y UX

1. **Aislamiento multi-tenant y control de acceso**:
   - Solo `INSTITUTION_ADMIN` puede activar o desactivar fuentes financieras.
   - Las operaciones se gestionan a través de `TenantContextGuard` y `DatabaseUnitOfWork`, garantizando que ninguna solicitud de Banco X pueda alterar las fuentes de Banco Y (`403 Forbidden`).
   - Las operaciones emiten eventos de auditoría trazables: `BUREAU_MOCK_ENABLED` y `BUREAU_MOCK_DISABLED`.

2. **Diferenciación de estados (CA-13.01, CA-13.08, CA-13.09)**:
   - **Habilitación institucional**: refleja si la entidad decidió incorporar la fuente a sus evaluaciones (`Habilitada para la institución` / `No habilitada`).
   - **Salud técnica del proveedor**: refleja el estado técnico del proveedor en la plataforma (`Salud técnica: Operativa`, `Degradada` o `No disponible`). Una fuente habilitada nunca se anuncia como "operativa" si su salud técnica no lo corrobora.
   - **Ausencia de antecedentes (Sin datos)**: se explica que la habilitación no garantiza antecedentes para todos los solicitantes. Si no hay datos, el sistema reportará `NO_DATA` sin interrumpir la evaluación.

3. **Cero credenciales técnicas (CA-13.03)**:
   - No se solicitan URLs, API keys, secretos ni parámetros técnicos en la interfaz. La arquitectura SOA y los adaptadores de integración residen encapsulados en el backend.

4. **Navegación independiente (CA-13.10)**:
   - Fuentes financieras (`/fuentes-financieras`) y Productos (`/productos`) se operan como secciones independientes desde el menú lateral y desde la barra de acciones inferior, sin obligar al usuario a reiniciar el asistente inicial.

5. **Limitación de cobertura (CA-13.11)**:
   - Se muestra explícitamente la cobertura orientada a solicitantes particulares y personas naturales antes de habilitar la fuente.

## Endpoints del backend

- `GET /api/institution/tenants/:tenantSlug/home`: retorna `sources: SourceItemDto[]` con nombre, propósito, cobertura, disponibilidad, salud técnica y estado de habilitación, manteniendo `source: { available, enabled }` para retrocompatibilidad con la preparación inicial de Sprint 2.
- `POST /api/institution/tenants/:tenantSlug/source/bureau`: habilita o deshabilita Buró Mock (`{ enabled: boolean }`).
- `POST /api/institution/tenants/:tenantSlug/sources/:sourceCode`: endpoint unificado para alternar fuentes por código.

## Migración

- `prisma/migrations/20261011110000_hu13_bureau_mock_provider/migration.sql`: inserta de manera idempotente el registro `BUREAU_MOCK` en `IntegrationProvider` con categoría `CREDIT_BUREAU` y estado `ACTIVE`.
